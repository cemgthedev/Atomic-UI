## Estrutura do componente

O `RadioGroupItem` deve sempre estar dentro de um `RadioGroup`, que controla o valor selecionado.

---

## Propriedades

### RadioGroup

- `defaultValue` — Define o valor selecionado inicialmente.
- `value` — Controla o valor selecionado do grupo.
- `onValueChange` — Callback executado quando a seleção muda.
- `disabled` — Desabilita todos os itens do grupo.
- `className` — Classes adicionais aplicadas ao contêiner.

### RadioGroupItem

- `value` — Identificador único do item dentro do grupo.
- `variant` — Define a aparência visual do item.
- `size` — Controla o tamanho do indicador.
- `rounded` — Define o formato das bordas.
- `disabled` — Desabilita apenas o item atual.
- `className` — Classes adicionais aplicadas ao item.

## Acessibilidade

O componente é construído sobre o **Radix UI RadioGroup**, oferecendo suporte nativo a:

- Navegação por teclado com `Tab` e setas direcionais.
- Seleção de apenas uma opção por grupo.
- Estados `checked`, `disabled` e `focus-visible`.
- Compatibilidade com leitores de tela através dos papéis `radiogroup` e `radio`.

Para melhor acessibilidade, associe cada `RadioGroupItem` a um `Label`.
